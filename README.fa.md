# دیپی

**دیپی** یک برنامهٔ رایگان و آفلاین برای اندروید است؛ برای کارگرها و
پیمانکارها. روزهای کاری و پرداخت‌ها را روی تقویم شمسی ثبت می‌کنی و همیشه
می‌دانی چه کسی چقدر بدهکار است. همهٔ داده‌ها روی گوشی خودت می‌ماند — بدون
حساب کاربری، بدون ثبت‌نام و بدون نیاز به اینترنت.

## ویژگی‌ها

- **تقویم کار** — هر روز کاری را روی تقویم شمسی ثبت می‌کنی؛ رنگ هر روز رنگ
  کارفرماست و کارت پایین تقویم خلاصهٔ همان روز را نشان می‌دهد.
- **مدیریت کارفرما** — افزودن، ویرایش، بایگانی و حذف کارفرما همراه با رنگ،
  شمارهٔ تلفن، یادداشت و دستمزد پیش‌فرض هرکدام.
- **ثبت پرداخت و مانده‌حساب** — پرداخت هر کارفرما را ثبت می‌کنی و مانده‌حساب
  («طلب شما» یا «بدهی شما») را یک‌نگاه می‌بینی.
- **آمار** — جمع روزهای کاری، دستمزد و پرداخت‌ها، نمودار میله‌ای ماهانه و یک
  کارت برای هر کارفرما.
- **کاملاً آفلاین** — بدون سرور، بدون حساب کاربری و بدون هیچ تماس اینترنتی
  برای داده‌هایت.
- **بدون ثبت‌نام** — نصب می‌کنی و شروع می‌کنی؛ چیزی برای ثبت‌نام نیست.
- **پشتیبانی از فارسی و راست‌به‌چپ** — رابط کاربری کاملاً راست‌به‌چپ با
  عددهای فارسی.
- **پشتیبان‌گیری خودکار JSON روی گوشی** — برنامه هر ۱۲ ساعت یک فایل پشتیبان
  JSON روی حافظهٔ گوشی می‌نویسد و چند نسخهٔ آخر را نگه می‌دارد.
